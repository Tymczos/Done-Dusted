# Bundled font licenses

All font binaries are unmodified, offline assets. Inter, Caveat, Dancing Script, Libre Baskerville and Lora use the SIL Open Font License 1.1. Special Elite uses the Apache License 2.0. The accompanying license files retain the original terms and notices. No font licensing or service subscription is required at runtime.

Source packages obtained through the npm registry, with npm's package integrity verification:

| Preview name   | Font                      | Source package                             |
| -------------- | ------------------------- | ------------------------------------------ |
| Everyday       | Inter (Regular, SemiBold) | @expo-google-fonts/inter 0.4.2             |
| The Notebook   | Caveat Medium             | @expo-google-fonts/caveat 0.4.2            |
| Soft Script    | Dancing Script Medium     | @expo-google-fonts/dancing-script 0.4.2    |
| The Classic    | Libre Baskerville Regular | @expo-google-fonts/libre-baskerville 0.4.3 |
| The Typewriter | Special Elite Regular     | @expo-google-fonts/special-elite 0.4.1     |
| Bookish        | Lora Regular              | @expo-google-fonts/lora 0.4.2              |

The Expo Google Fonts packages are acquisition sources, not runtime dependencies. Only the seven selected font files and their license notices are bundled. Font previews and selected large headings use these actual font files; no generic cursive fallback is used. Body text uses Inter for readability.
